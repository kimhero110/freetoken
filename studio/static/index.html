探针能回答什么？

接口体检记录能力是否可用。能力对照探针比较指定参考与待测接入在同一题集中的表现。结果不能确定底层模型身份、替换型号或服务商意图。

参考与调用

先在你信任的接入运行能力探针，再用报告作为参考。同一浏览器会话内引用7天以内的报告，复用版本、题集和调用参数。参考来源由你指定，不自动认证为官方。服务商仍可能改写参数。

实验性判定规则

18道参数化任务，每题2次。按题配对，至少17题两次响应均有效，且参考通过率≥80%。通过率下降≥20个百分点且单侧配对符号检验 p≤0.01 时提示能力偏离。题目相关性、多次比较与未完成真实模型校准会限制统计解释；p值不是模型被替换的概率。

请求失败、截断和空响应作为不可用样本；不足时不给降级结论。无显著差异不代表真模型，也不排除按时段、负载或任务类型发生的降级。本版不提供持续监控或自动复测。

计费边界

订阅周期摊销与文本 API 按量分开。聚合服务可填写实际支付和到账计费单位；必须确认单价已包含全部倍率。复杂阶梯、税费、图片与工具收费未纳入。测试费用为观测用量估算，不是账单对账。

数据与历史

Key仅用于本次调用。报告属于当前浏览器会话，清除Cookie会失去访问权。旧版评分不适用于新版判定，请重新探测。
