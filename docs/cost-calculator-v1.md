# 成本计算器 V1

主站 `/cost/` 与 `/en/cost/` 提供浏览器本地预算。首页、导航、44 个平台的中英文详情页提供入口；接口质量评测链接指向 `https://test.witkit.zone/`。快速和深度评测继续属于质量工具，本次没有加入真实 API 计费探测。

## 数据与计算

- `data/pricing/pricebook.json` 独立于免费额度资料，记录模型版本、币种、每百万 token 单价、来源、核查日期和版本。
- 首批记录为 DeepSeek V4 Flash / Pro，价格核查于 2026-09-06。`documented` 仅表示官方文档证据，不是实测账单。更新需通过正常代码审查 PR；禁止爬虫直接覆盖发布价格。
- 高峰与非高峰用量分别计算。输入总量包含缓存命中，输出应包含所有计费推理 tokens。
- BigInt 固定精度保存万亿分之一货币单位；最终显示四舍五入至 6 位小数，未知必要单价不产生合计。
- 自填报价不视为已核验数据。免费抵扣仅使用用户确认的适用余额，不解析平台自然语言额度。汇率由用户明确提供；不同币种或不同模型不直接排序。
- 不检查容量可用性，不把平均用量当峰值需求。报价超过 30 天提示复核。无密钥输入、持久化存储或计算器分析上报。

## 发布与后续

执行 `npm --prefix site test`、`npm --prefix site run build`，以及仓库 Python 与 SDK 集成测试。构建本身校验价格数据，CI 冒烟覆盖两种语言的成本页面。

评测站源码需单独定位，接入时增加主站预算链接、保持现有快速/深度质量预设，再逐步实现成本实测和报告预算对照。不得把网关自报费用标作账单真值，也不得把费用并入质量总分。
